# Guia de Contribuição

Obrigada por considerar contribuir para este projeto! 🎉

## Como Contribuir

### Reportando Problemas

Se você encontrou um bug ou tem uma sugestão:

1. Verifique se já não existe uma issue aberta sobre o assunto
2. Crie uma nova issue descrevendo claramente:
   - O problema encontrado ou a sugestão
   - Passos para reproduzir (se aplicável)
   - Comportamento esperado vs. comportamento atual

### Propondo Mudanças

1. Fork o repositório
2. Crie uma branch para sua feature (`git checkout -b feature/minha-feature`)
3. Faça suas alterações
4. Teste suas alterações
5. Commit suas mudanças (`git commit -m 'Adiciona minha feature'`)
6. Push para a branch (`git push origin feature/minha-feature`)
7. Abra um Pull Request

## Diretrizes de Código

### Código R

- Use espaçamento consistente (2 espaços para indentação)
- Documente funções com comentários claros
- Use nomes descritivos para variáveis e funções
- Siga o estilo do tidyverse quando possível

### Commits

- Use mensagens de commit descritivas em português
- Comece com um verbo no imperativo (Adiciona, Corrige, Atualiza, etc.)
- Mantenha a primeira linha com menos de 72 caracteres

## Padrões do Projeto

- Scripts devem estar em `meu_projeto/scripts/`
- Funções reutilizáveis em `meu_projeto/funcoes/`
- Dados em `meu_projeto/dados/`
- Figuras geradas em `meu_projeto/figuras/`
- Resultados em `meu_projeto/output/`

## Código de Conduta

Este projeto adota um código de conduta baseado em respeito e colaboração:

- Seja respeitoso com outros colaboradores
- Aceite críticas construtivas
- Foque no que é melhor para a comunidade
- Mostre empatia com outros membros da comunidade

## Dúvidas?

Se tiver alguma dúvida, sinta-se à vontade para:

- Abrir uma issue de discussão
- Entrar em contato através do [LinkedIn](https://www.linkedin.com/in/jennifer-luz-lopes/)
